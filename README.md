# Ed-Novate Africa

A public website for **Ed-Novate Africa**, an EdTech and talent platform from Gomindz Academy. It takes young people in West Africa from career discovery to verified skills and real work.

The site is a static Vite + React app. Copy is drawn from Ed-Novate’s education-to-employment proposal: the skills-to-jobs gap, the Discover → Learn → Build → Prove → Get hired pathway, the Skills Passport, employer matching, and the three-year impact targets.

## Run locally

```bash
npm install
npm run dev
```

The dev server listens on [http://127.0.0.1:4327](http://127.0.0.1:4327).

```bash
npm run build
npm run preview
```

## What’s on the site

- **Home** — problem, pathway, traction from Gomindz Academy, and who the platform is for
- **Pathway** — the five learner steps and five product phases
- **Learners** — career counselling, competency-based learning, and the first Gambian cohort
- **Employers** — verified Skills Passports and a talent pipeline
- **Impact** — NEET context, ECOWAS expansion, and SDG alignment
- **Join** — waitlist for learners, employers, and partners

The waitlist is stored in the browser for this preview. Production should send submissions to the Gomindz team at `academy@gomindz.gm`.
